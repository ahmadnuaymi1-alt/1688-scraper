# Setup & Handoff Guide

This guide gets a fresh machine from a clone to a fully working **1688 Scraper** with
**Agent mode** — the end-to-end pipeline that takes a single 1688 URL and produces a
Shopify-ready product (scrape → clean variants → dimensions → hero images → lifestyle
images → pricing → rules → review page).

Read this top to bottom the first time. The single most-missed step is the
**Higgsfield image CLI** (section 4) — without it, every image-generation stage fails.

---

## 1. Prerequisites

| Requirement | Notes |
|---|---|
| **Node.js 20+** | `node -v` to check. |
| **Git** | To clone the repo. |
| **Claude Code** | Agent mode and all the `/skills` run *inside* Claude Code (VS Code extension or CLI). You need it installed and signed in to your own Anthropic account. The skills live in `.claude/skills/` in this repo and load automatically when you open the folder. |
| **Higgsfield account** | For hero/lifestyle/close-up image generation (section 4). |
| **Accounts/keys** | See section 2. |

> Agent mode is **driven by Claude Code**: Claude reads the `.claude/skills/agent-mode`
> skill, makes the judgment calls (variant naming, scene authoring), and runs the
> `scripts/agent-mode.ts` orchestrator for the mechanical pipeline. So step one for the
> recipient is: open this folder in Claude Code.

## 2. Accounts & API keys

Create these and copy the keys into `.env.local` (see section 3). Everything marked
**required** must be set for the core pipeline to run.

| Service | Env var(s) | Required? | What it's for |
|---|---|---|---|
| **Supabase** (Postgres + Storage) | `DATABASE_URL`, `DIRECT_URL`, `SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `SUPABASE_STORAGE_BUCKET` | ✅ | Database + product image storage. Free tier works. |
| **Bright Data** (Web Unlocker) | `BRIGHT_DATA_TOKEN`, `BRIGHT_DATA_ZONE` | ✅ | Scrapes 1688/AliExpress past bot protection. |
| **Anthropic** | `ANTHROPIC_API_KEY` | ✅ | Claude for titles/descriptions/variant cleanup/OCR. |
| **Google Gemini** | `GEMINI_API_KEY`, `GEMINI_VISION_API_KEY` | ✅ | Image OCR + hero/lifestyle vision QA. Same key can fill both. |
| **iron-session** | `SESSION_SECRET` | ✅ | App login. Generate with `openssl rand -base64 48`. |
| **Higgsfield** | *(CLI, not an env var — see section 4)* | ✅ for images | Hero + lifestyle + close-up image generation. |
| **OpenAI** | `OPENAI_API_KEY` | Optional | Only for the GPT-backed description/title rules. |
| **Shopify** | `SHOPIFY_STORE_DOMAIN`, `SHOPIFY_ADMIN_TOKEN` | Optional | One-click auto-upload of finished products. |
| **Teemdrop** | `TEEMDROP_EMAIL`, `TEEMDROP_PASSWORD` | Optional | Only for the `/dimension-scanner` skill. |

## 3. Install & configure

```bash
git clone <this-repo-url>
cd 1688-scraper
npm install

# Configure environment
cp .env.example .env.local
#  → open .env.local and fill in every REQUIRED value from section 2

# Create the database schema (Prisma → your Supabase Postgres)
npx prisma migrate deploy

# Start the app
npm run dev
```

Then open <http://localhost:3000>, create the first account on the signup page, and
you're in. (`npm run dev` runs through `scripts/dev-guarded.mjs`, which clears a stale
`.next` cache on every start — this is intentional and prevents a known dev-server crash loop.)

> First-time Supabase helpers (optional): `node scripts/bootstrap-schema.mjs` and
> `node scripts/bootstrap-bucket.mjs` can create the schema and the storage bucket if you
> prefer scripts over the Supabase dashboard.

## 4. Higgsfield image CLI (the easy-to-miss step)

Hero, lifestyle, and close-up images are generated by driving the **official Higgsfield
CLI** — a separate command-line tool, **not** an npm dependency of this repo and **not**
configured through `.env.local`.

1. **Install the official Higgsfield CLI** so the `higgsfield` command is on your PATH.
   Verify with:
   ```bash
   higgsfield --version
   ```
2. **Log in** to your Higgsfield account:
   ```bash
   higgsfield auth login
   ```
   This writes your tokens to `~/.config/higgsfield/credentials.json` — that file is what
   the pipeline reads. (On Windows this is under your user profile's `.config\higgsfield\`.)
3. **Check credits:**
   ```bash
   higgsfield account status
   ```
   Each Nano-Banana image costs ~2 credits, so a full product (heroes + 6–8 lifestyles +
   close-ups) uses a few dozen credits.
4. **(Optional) second account for auto-failover:** the pipeline will fall back to a backup
   account if the active one runs out of credits mid-run. To enable it, log into the second
   account and copy its credentials file to
   `~/.config/higgsfield/credentials.backup.json`. If you don't set this up, image
   generation simply stops when credits run out (no failover) — that's fine for a single account.

If the `higgsfield` command isn't found or isn't logged in, the hero/lifestyle stages of
Agent mode will fail while the scrape/text stages still succeed.

## 5. Running Agent mode

Inside Claude Code (with this folder open), give it a 1688 URL and ask for agent mode —
e.g. **"use agent mode on this URL: <1688-url>"** or **`/agent-mode <url>`**. Claude will:

1. Scrape the listing and run Phase 2 (variant cleanup, Vision renames, dimensions, product type).
2. Generate hero images (one per unique variant image) via Higgsfield.
3. Author per-product lifestyle scenes and generate 6–8 lifestyle + close-up images.
4. Price the variants and apply the description/title rules.
5. Delete the original supplier images (keeping any you've starred).
6. Hand you a `/review/<productId>` page that's ready to push to Shopify.

You can also run individual skills on their own: `/hero-image-creator`,
`/lifestyle-image-creator`, `/variant-double-checker`, `/dimension-scanner`, etc. They're
all in `.claude/skills/`.

## 6. Notes & known limitations

- **Scene-library fallback removed.** This release excludes the large (~460 MB) scraped
  `scene-library/` used by the *old* keyword-based scene matcher. Agent mode doesn't need
  it — it authors fresh scene-overrides per product. The only thing that won't work is the
  legacy `lifestyle-scene-designer` library-matcher fallback when no override file exists.
- **Per-product overrides aren't shipped.** `scene-overrides/` and `hero-overrides/` are
  generated per product at run time; this release starts empty and fills as you run products.
- **This is a customized Next.js build.** See `AGENTS.md` — read the relevant guide in
  `node_modules/next/dist/docs/` before changing framework-level code.
